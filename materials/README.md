# materials/ — 資料の受け渡しフォルダ（GitHub には上がりません）

Claude に読ませたい資料（PDF・Excel・画像・メモなど）は、このフォルダに入れてください。

## 使い方

1. このフォルダを開く:

   **Windows**: エクスプローラーのアドレスバーに貼り付けて Enter:

   ```
   \\wsl.localhost\Ubuntu\home\自分のユーザー名\projects\自分のプロジェクト名（フォルダ名）\materials
   ```

   （「自分のユーザー名」は Ubuntu で `whoami` と打つと確認できます。
   よく使うなら右クリック →「クイックアクセスにピン留め」しておくと、
   以後はドラッグ＆ドロップだけで渡せます）

   **Mac**: Finder で ⌘+Shift+G を押して貼り付け:

   ```
   ~/projects/自分のプロジェクト名（フォルダ名）/materials
   ```

   （よく使うなら Finder のサイドバーへドラッグして登録しておくと便利です）

2. ファイルを入れたら、Claude にこう頼む:
   「materials の 見積もり.xlsx を読んで要約して」

## corpus-dataset.js について

`corpus-dataset.js` は `sms-corpus.md`（実文例集）を `docs/mockups/ui-mock.html` が読み込める
JavaScript の形に変換したものです。このファイルをここに置くと、モックが実文例と実データの汚れ
（テンプレート名空欄・個人宛の下書き・店舗違いの複製・過去版など）を表示するようになります。
無ければ架空のダミーデータで動くので、必須ではありません。

作り方・スキーマは `docs/DEVELOPMENT_PLAN.md`「実文例調査（sms-corpus.md）との突合結果」を参照してください。

## このフォルダの性質

- ここに置いたファイルは **git 管理外**です（コミットしても GitHub に上がらない設定済み）。
  社外秘資料・顧客情報を含むファイルを Claude に参照させたいときの置き場として使えます
- **バックアップはされません**（git 管理外のため）。原本は必ず共有ドライブ等にも保持し、
  ここには「コピー」を置いてください
