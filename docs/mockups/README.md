# 画面モックアップ

`ui-mock.html` は SMS文例検索ツールの**画面イメージを掴んでもらうための単体HTMLファイル**です。
Next.js アプリの実装ではなく、見た目と操作感だけを確認するためのものです。

## ⚠️ ダミーデータのみです

このファイル内の会社名・店舗名・テンプレート名・本文・電話番号・URL・送信通数は、
**すべて架空のもの**です。実際の BigQuery データは一切含まれていません。
安心して社内の誰にでも共有できます。

（例外: 「② 文章案をつくる」の文字数・通数・料金の**計算式だけ**は、社内で実際に使っている
申請書の数式をそのまま再現しています。文面や会社名などのデータは引き続きすべて架空です）

## 開き方

インストール作業は不要です。ファイルをダブルクリックするだけでブラウザが開きます。

**Windows の場合**:

エクスプローラーのアドレスバーに以下を貼り付けて Enter:

```
\\wsl.localhost\Ubuntu\home\<自分のユーザー名>\projects\SMS-text-helper\docs\mockups
```

（`<自分のユーザー名>` は Ubuntu で `whoami` と打つと確認できます）

表示された `ui-mock.html` をダブルクリックすると、既定のブラウザで開きます。

**期待結果**: ブラウザに「SMS文例検索ツール」の検索・一覧画面が表示される

**失敗時**: フォルダが見当たらない → DevContainer が起動しているか確認してください（このパスはコンテナのファイルをホストから見るための特殊な場所です）

## 3ステップの流れ

画面上部のステップナビ「① 文例をさがす → ② 文章案をつくる → ③ 依頼文を出す」で行き来できます。

### ① 文例をさがす

- キーワード検索（本文・テンプレート名）
- 絞り込み（クライアント／フランチャイズ／利用シーン／車検何ヶ月前／SMSの型／使用中の文例だけ表示する）
- 「テスト用の文例も表示する」「車のナンバーが書かれた文例も表示する」のチェック（既定は両方 OFF）
- 並び替え（よく送られている順・新しい順）
- **カードのどこを押しても選択**できます（チェックとハイライトが付きます）。1件以上選ぶと画面下部にバーが出て、「② 文章案をつくる」へ進めます
- 「詳細」ボタンを押すと詳細パネルが開きます（選択には影響しません）。この文面だけをコピーしたい場合は詳細パネルの中の「この文面だけコピー」を使ってください

### ② 文章案をつくる

- SMSの型（テキスト／入庫連動／リマインド）を選ぶと、文字数の計算式が切り替わる。**①で最初に選んだ文例の型に応じて自動で選ばれます**（テキスト⇔入庫連動を混ぜて選ぶと注意が表示されます）
- ①で選んだ文例が本文つきで並びます。**「この本文を貼り付け」を押すと、文章案にコピペされます**（やっていることはコピペそのものなので、何度でも押せます）
- 貼り付けを取り消したいときは **Ctrl+Z**、または文章案の下の **「↩ 元に戻す」** を押してください。手で編集を始めると「元に戻す」は対象外になります（編集内容まで消えてしまわないようにするため）
- 選択から外したい文例は、右上の **×** を押してください
- 文字数・通数・料金がリアルタイムに表示される（**社内で実際に使っている申請書の数式をそのまま再現**）
- 通数が増える直前は警告が出る（費用に直結するため）
- リマインドを選ぶと置換変数（`@customer_name@` 等）のボタンが出る（※ダミーデータにリマインドの文例はありません。手動で試す場合にお使いください）
- 準備ができたら「依頼文をつくる →」で③へ進めます

### ③ 依頼文を出す

- 「今回依頼する設定」（作業内容・停止状態・SMSの型・テンプレート名など、申請書と同じ項目）を入力
- 文章案・文字数・参考にした文例をまとめた依頼文をプレビューし、「依頼文をコピー」でコピーできる（**一覧からのコピーは無く、コピーの出口はここと①の詳細パネルの2箇所だけです**）
- **このツールから Slack へは投稿しません**。コピーした依頼文を手動で貼り付ける運用です
- 文章案が空のまま③に来た場合は、②へ戻る案内が表示されます

**伏せモード**トグルは全ステップに効きます。ON にすると画面上部に帯が出て、会社名だけでなく本文中に直書きされた店舗名・電話番号・URL もマスクされます（列を隠すだけでは不十分だった、という設計上の教訓を反映）。詳細パネル・依頼文プレビューにも同様にかかります。

**例外**: 「② 文章案をつくる」の**編集欄（自分で打ち込む欄）だけは伏せません**。伏せてしまうと自分で文章を直せなくなるためです。伏せモード中はその旨の注意書きが編集欄の上に出ます。

**フランチャイズについて**: 「車検のコバック」「車検の速太郎」のようなブランド名そのものは、複数店舗にまたがるカテゴリ名なので伏せモードでもマスクしません。マスクするのは「車検のコバック岡山円山店」のように**特定の店舗まで分かる形**になったときだけです。

一括CSVエクスポートは受け入れ条件で明示的に除外されているため、このモックにも付けていません。
