# 画面モックアップ

`ui-mock.html` は SMS文例検索ツールの**画面イメージと使い心地を掴んでもらうための単体HTMLファイル**です。
Next.js アプリの実装ではなく、見た目と操作感だけを確認するためのものです。

## データは二段構えです

このファイルは、同じフォルダ構成の `materials/corpus-dataset.js` があれば**実文例**を、
無ければ**架空のダミーデータ**を表示します。`materials/` は git 管理外なので、
clone 直後・このリポジトリの外に共有した状態では自動的にダミー表示になります。

| 状態 | 見分け方 | 中身 |
|---|---|---|
| 実データ表示中 | 画面上部に赤い帯「⚠ 実データ表示中」が出る。伏せモードが**自動で ON** になる | 実在のクライアント名・店舗名・電話番号・短縮URLを含む（`materials/sms-corpus.md` を変換したもの） |
| ダミー表示中 | 赤帯が出ない。バッジが「画面モックアップ（ダミーデータ）」のまま | すべて架空 |

**実データを入れて開いた画面は社外・画面共有厳禁です。** 伏せモードは自動でONになりますが、
「② 文章案をつくる」の編集欄だけは伏せられない仕様なので、そこに実データの本文を貼った状態で
画面共有しないよう注意してください。

営業メンバーに配る・社外に見せるときは、`materials/corpus-dataset.js` を置かない
（＝ダミー表示のまま）状態で共有してください。ダミーデータのみのときは、
**すべて架空のデータ**です。安心して社内の誰にでも共有できます。

（例外: 「② 文章案をつくる」の文字数・通数・料金の**計算式だけ**は、社内で実際に使っている
申請書の数式をそのまま再現しています。日本語の差し込みタグ（`@車検満了日@` 等）を含む文面では、
主表示は申請書どおりのまま、実配信時の見込み文字数を補助表示として出します）

## 開き方

インストール作業は不要です。ファイルをダブルクリックするだけでブラウザが開きます。

**Windows の場合**:

エクスプローラーのアドレスバーに以下を貼り付けて Enter:

```
\\wsl.localhost\Ubuntu\home\<自分のユーザー名>\projects\SMS-text-helper\docs\mockups
```

（`<自分のユーザー名>` は Ubuntu で `whoami` と打つと確認できます）

表示された `ui-mock.html` をダブルクリックすると、既定のブラウザで開きます。

**期待結果**: ブラウザに「SMS文例検索ツール」の検索・一覧画面が表示される

**失敗時**: フォルダが見当たらない → DevContainer が起動しているか確認してください（このパスはコンテナのファイルをホストから見るための特殊な場所です）

## 3ステップの流れ

画面上部のステップナビ「① 文例をさがす → ② 文章案をつくる → ③ 依頼文を出す」で行き来できます。

### ① 文例をさがす

- キーワード検索（本文・テンプレート名）
- 絞り込み（クライアント／フランチャイズ／利用シーン／車検何ヶ月前／SMSの型／**顧客区分**／**アプローチ段階**）
- 表示に含める（既定はすべて OFF）: 「使用中止の文面（【使用不可】）も表示する」「個人宛の文例も表示する」「テスト用の文例も表示する」「車のナンバーが書かれた文例も表示する」
- 「店舗違いをまとめる」（既定 ON）: 同一文面が店舗名・電話番号だけ違って複製登録されているとき、1枚のカードに集約して「＋他N店舗」から展開できます。OFF にすると実登録件数どおりに1件ずつ表示します
- 利用シーンのタグは**0件でも消えません**（グレー表示）。実例が見つからなかったこと自体が「実務で使われていない可能性」という判断材料になるためです
- テンプレート名が空の文例は「利用シーン｜本文冒頭」の形で自動的に見出しを作ります
- 並び替え（よく送られている順・新しい順）
- **文章案として選ぶのは、カード左上のチェックボックスだけです**。チェックを入れると1件以上選んだ状態になり、画面下部にバーが出て「② 文章案をつくる」へ進めます
- **カード本体（チェックボックス以外の部分）を押すと詳細パネルが開きます**（展開した店舗一覧の中を押した場合を除く）。この文面だけをコピーしたい場合は詳細パネルの中の「この文面だけコピー」を、文章案に加えたい場合は詳細パネルの「＋ 文章案に追加」を使ってください。詳細パネルには顧客区分・アプローチ段階・エリア・店舗・使用中/使用中止の状態区分・この文例の入手元（実データ表示時）・使用中止版との比較も出ます

### ② 文章案をつくる

- SMSの型（テキスト／入庫連動／リマインド）を選ぶと、文字数の計算式が切り替わる。**①で最初に選んだ文例の型に応じて自動で選ばれます**（テキスト⇔入庫連動を混ぜて選ぶと注意が表示されます）
- ①で選んだ文例が本文つきで並びます。**「この本文を貼り付け」を押すと、文章案にコピペされます**（やっていることはコピペそのものなので、何度でも押せます）
- 貼り付けを取り消したいときは **Ctrl+Z**、または文章案の下の **「↩ 元に戻す」** を押してください。手で編集を始めると「元に戻す」は対象外になります（編集内容まで消えてしまわないようにするため）
- 選択から外したい文例は、右上の **×** を押してください
- 文字数・通数・料金がリアルタイムに表示される（**社内で実際に使っている申請書の数式をそのまま再現**）。日本語の差し込みタグ（`@車検満了日@` 等）を含む文面では、その下に「実配信時の見込み文字数」が補助的に表示されます（主表示の数式自体は変えていません）
- 通数が増える直前は警告が出る（費用に直結するため）
- リマインドを選ぶと置換変数（`@customer_name@` 等）のボタンが出る
- 準備ができたら「依頼文をつくる →」で③へ進めます

### ③ 依頼文を出す

- 「今回依頼する設定」（作業内容・停止状態・SMSの型・テンプレート名など、申請書と同じ項目）を入力
- 文章案・文字数・参考にした文例をまとめた依頼文をプレビューし、「依頼文をコピー」でコピーできる（**一覧からのコピーは無く、コピーの出口はここと①の詳細パネルの2箇所だけです**）
- **このツールから Slack へは投稿しません**。コピーした依頼文を手動で貼り付ける運用です
- 文章案が空のまま③に来た場合は、②へ戻る案内が表示されます

**伏せモード**トグルは全ステップに効きます。ON にすると画面上部に帯が出て、会社名だけでなく本文中に直書きされた店舗名・電話番号・URL もマスクされます（列を隠すだけでは不十分だった、という設計上の教訓を反映）。詳細パネル・依頼文プレビューにも同様にかかります。

**例外**: 「② 文章案をつくる」の**編集欄（自分で打ち込む欄）だけは伏せません**。伏せてしまうと自分で文章を直せなくなるためです。伏せモード中はその旨の注意書きが編集欄の上に出ます。

**フランチャイズについて**: 「車検のコバック」「車検の速太郎」のようなブランド名そのものは、複数店舗にまたがるカテゴリ名なので伏せモードでもマスクしません。マスクするのは「車検のコバック岡山円山店」のように**特定の店舗まで分かる形**になったときだけです。

一括CSVエクスポートは受け入れ条件で明示的に除外されているため、このモックにも付けていません。

## 実データを読み込ませたいとき

`materials/corpus-dataset.js` を置くと、このファイルはそちらを自動で読み込みます（同一フォルダ構成の
`docs/mockups/ui-mock.html` から見て `../../materials/corpus-dataset.js`）。ファイルの作り方・出典は
`materials/README.md` と `docs/DEVELOPMENT_PLAN.md`「実文例調査（sms-corpus.md）との突合結果」を参照してください。
`materials/` は git 管理外なので、実データを入れてもリポジトリにはコミットされません。

## これは何のためのものか

営業メンバーに「こういう道具です」を言葉なしで伝えるためのものです。フィードバックをもらったら、
このファイルを直接書き換えて調整します（Next.js への実装移行は依存ライブラリ確定後、別途行います）。
