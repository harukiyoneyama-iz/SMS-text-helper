# 画面モックアップ

`ui-mock.html` は SMS文例検索ツールの**画面イメージを掴んでもらうための単体HTMLファイル**です。
Next.js アプリの実装ではなく、見た目と操作感だけを確認するためのものです。

## ⚠️ ダミーデータのみです

このファイル内の会社名・店舗名・テンプレート名・本文・電話番号・URL・送信通数は、
**すべて架空のもの**です。実際の BigQuery データは一切含まれていません。
安心して社内の誰にでも共有できます。

（例外: 「② 文章案をつくる」の文字数・通数・料金の**計算式だけ**は、社内で実際に使っている
申請書の数式をそのまま再現しています。文面や会社名などのデータは引き続きすべて架空です）

## 開き方

インストール作業は不要です。ファイルをダブルクリックするだけでブラウザが開きます。

**Windows の場合**:

エクスプローラーのアドレスバーに以下を貼り付けて Enter:

```
\\wsl.localhost\Ubuntu\home\<自分のユーザー名>\projects\SMS-text-helper\docs\mockups
```

（`<自分のユーザー名>` は Ubuntu で `whoami` と打つと確認できます）

表示された `ui-mock.html` をダブルクリックすると、既定のブラウザで開きます。

**期待結果**: ブラウザに「SMS文例検索ツール」の検索・一覧画面が表示される

**失敗時**: フォルダが見当たらない → DevContainer が起動しているか確認してください（このパスはコンテナのファイルをホストから見るための特殊な場所です）

## 3ステップの流れ

画面上部のステップナビ「① 文例をさがす → ② 文章案をつくる → ③ 依頼文を出す」で行き来できます。

### ① 文例をさがす

- キーワード検索（本文・テンプレート名）
- 絞り込み（クライアント／フランチャイズ／利用シーン／車検何ヶ月前／SMSの型／使用中のみ）
- 「テスト用を含める」「ナンバー記載を含める」のチェック（既定は両方 OFF）
- 並び替え（よく送られている順・新しい順）
- 詳細パネルの開閉、本文コピー
- 気に入った文例は「＋ 文章案に追加」で②に送れる

### ② 文章案をつくる

- SMSの型（テキスト／入庫連動／リマインド）を選ぶと、文字数の計算式が切り替わる
- ①で追加した文例の本文をワンクリックで文章案に挿入し、自由に編集できる
- 文字数・通数・料金がリアルタイムに表示される（**社内で実際に使っている申請書の数式をそのまま再現**）
- 通数が増える直前は警告が出る（費用に直結するため）
- リマインドを選ぶと置換変数（`@customer_name@` 等）のボタンが出る

### ③ 依頼文を出す

- 「今回依頼する設定」（作業内容・停止状態・SMSの型・テンプレート名など、申請書と同じ項目）を入力
- 文章案・文字数・参考にした文例をまとめた依頼文をプレビューし、コピーできる
- **このツールから Slack へは投稿しません**。コピーした依頼文を手動で貼り付ける運用です

**伏せモード**トグルは全ステップに効きます。ON にすると会社名だけでなく、本文中に直書きされた店舗名・電話番号・URL もマスクされます（列を隠すだけでは不十分だった、という設計上の教訓を反映）。文章案・依頼文プレビューにも同様にかかります。

一括CSVエクスポートは受け入れ条件で明示的に除外されているため、このモックにも付けていません。
