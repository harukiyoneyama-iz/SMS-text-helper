# ツール実行時の解説ルール

## 解説が必要な場面（副作用のある操作のみ）

以下の操作は実行前に簡潔に説明する:
- 破壊的なBashコマンド（削除、上書き、外部通信）
- パッケージのインストール・アンインストール
- 外部サービスへのリクエスト（API呼び出し、デプロイ等）

## 解説不要な場面

以下は説明なしで実行してよい:
- ファイルの読み込み（Read, Glob, Grep）
- ファイルの編集・作成（コードの変更）
- Agent起動（探索、レビュー等）
- ビルド・テスト実行
- git操作（commit, status, diff等）

## 解説のスタイル

必要な場合も一文で簡潔に。冗長な説明は不要。
```
// GOOD
「tailwindcssをインストールします」

// BAD（過剰）
「UIスタイリングのためにtailwindcssパッケージをインストールします。これによりpackage.jsonとnode_modulesが変更されます」
```
